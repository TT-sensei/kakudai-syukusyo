# 拡大図と縮図ラボ（kakudai-syukusyo）

小学校第6学年 算数「拡大図と縮図」の学習アプリです。

公開先： https://tt-sensei.github.io/kakudai-syukusyo/

## 学習モード

### 1. 形のきまり
正三角形・正方形・正五角形・円などを比べ、「同じ名前の図形なら、いつでも拡大図・縮図になるのか」を考えます。答え合わせのあと、図形ごとの説明を確認できます。

### 2. 見分ける
2つの図形が拡大図・縮図の関係になっているかを判断します。対応する角の大きさと、対応する辺の長さの比に注目します。問題の順番はランダムで、間違えたときは正しい〇／×と理由を確認できます。

### 3. 作図ラボ
1セット8問です。次の基本図形から、図形の順番・倍率・方眼上の位置がランダムに出題されます。

- 直角三角形
- 二等辺三角形
- 三角形
- 台形
- 平行四辺形
- ひし形
- 長方形
- 正方形

倍率は **1/2倍・1.5倍・2倍** です。Aを中心に、各頂点を方眼の交点へ置いて作図します。点を置くと作図中の辺も順に表示されます。方向・距離の2段階ヒントと、間違えた点ごとの見直しメッセージがあります。8問のあとも、新しいランダムセットに続けて取り組めます。

図形は選んだ倍率で頂点が方眼の交点にくるように設計しています。作図板の端で点名が切れにくいよう、図形の配置範囲も計算しています。

### 4. 縮尺を使う
縮尺と図上の長さから実際の長さを求める問題、実際の長さから図上の長さを求める問題に取り組みます。問題の順番と選択肢の順番がランダムに変わり、答え合わせのあとに単位変換を含む解説を確認できます。

## 小6の学習ポイント

文部科学省の第6学年算数「縮図や拡大図」の資料を参考に、次の内容を入口として扱います。

- 縮図・拡大図の意味
- 対応する角の大きさが等しいこと
- 対応する辺の長さの比がどこでも一定になること
- 1つの点を中心にした拡大図・縮図の作図
- 縮尺を使って、直接測りにくい長さを求める考え方

本アプリは基本の確認用です。実際に定規や分度器を使って作図する学習や、校舎の高さを求めるような測量活動を置き換えるものではありません。

## 得点・進捗の保存

- 得点・加点済みの問題・練習済みモードは端末内に保存します。
- 同じ問題をやり直すことはできますが、同じ問題で得点を繰り返し獲得することはできません。
- 進捗保存用の共通部品が読み込めない場合も、localStorage による保存で練習済み状態を保持します。
- ブラウザのサイトデータを消去すると、端末内の得点や進捗も消去されます。

## 技術・共通素材

- HTML / CSS / Vanilla JavaScript の静的ページです。独自サーバー、データベース、APIキー、有料APIは使いません。
- ナビキャラは `TT-sensei/navi-character-` のWebP画像を参照しています。画像が読み込めなくても学習できます。
- 練習済み状態は `edu-components` の `StorageManager` / `ProgressManager` と連携しつつ、アプリ側のlocalStorageにも保存します。
- ナビキャラ素材の使用条件は、[素材リポジトリのライセンス](https://github.com/TT-sensei/navi-character-/blob/main/LICENSE)と利用ガイドを確認してください。素材ファイル自体はこのリポジトリへ複製していません。
- 設計方針は [edu-kit](https://github.com/TT-sensei/edu-kit) に合わせ、学習内容・操作を主役にし、キャラクターは補助として使います。
