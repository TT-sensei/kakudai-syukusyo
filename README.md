# 拡大図と縮図ラボ（kakudai-syukusyo）

小学校第6学年 算数「拡大図と縮図」の学習アプリです。

公開先： https://tt-sensei.github.io/kakudai-syukusyo/

## ファイル構成

- `index.html`：ミッション一覧（トップ画面）
- `explore.html`：形のきまり
- `judge.html`：拡大図・縮図の見分け
- `draw.html`：方眼での作図
- `scale.html`：地図・設計図・間取り図などで縮尺を使う12問
- `styles.css`：全画面で使う共通スタイル
- `js/common.js`：得点・進捗保存、ナビキャラ表示などの共通処理
- `js/home.js`：トップ画面の達成メッセージ
- `js/explore.js`、`js/judge.js`、`js/draw.js`、`js/scale.js`：各学習画面の処理

各ミッションは独立したHTMLです。トップのカードや「次のミッションへ」を押すと、対応するページに移動します。「ミッション一覧」でトップ画面へ戻れます。全ファイルは静的なHTML / CSS / JavaScriptで、ビルドや独自サーバーは不要です。

## 学習内容

### 1. 形のきまり
正三角形・正方形・正五角形・円などを比べ、「同じ名前の図形なら、いつでも拡大図・縮図になるのか」を考えます。答え合わせのあと、図形ごとの説明を確認できます。

### 2. 見分ける
2つの図形が拡大図・縮図の関係かを判断します。対応する角の大きさと、対応する辺の長さの比に注目します。問題の順番はランダムで、間違えたときは正しい〇／×と理由を確認できます。「重ねて確かめる」ではオレンジの図形をドラッグで移動し、大きさ・向きを調整できます。角の大きさを度数で表示して、形を重ねながら角を比べられます。

### 3. 作図ラボ
1セット8問です。直角三角形・二等辺三角形・三角形・台形・平行四辺形・ひし形・長方形・正方形から、図形・倍率・方眼上の位置がランダムに出題されます。倍率は1/2倍・1.5倍・2倍です。頂点を置くと作図中の辺も順に表示され、方向・距離の2段階ヒントと、点ごとの見直しメッセージがあります。「別の作図セット」で新しい問題に取り組めます。

### 4. 縮尺ミッション
地図・校内案内図・公園の設計図・部屋の間取り図・花だん・校庭・体育館のレイアウトなど、12の場面に取り組みます。実際の長さ・図上の長さ・縮尺そのものの3種類を求めます。各場面の図、条件、解説を表示し、問題と選択肢の順番をランダムに変えます。

## 得点・進捗の保存

- 得点・加点済みの問題・練習済みモードは端末内に保存します。
- 同じ問題をやり直せますが、同じ問題で得点を繰り返し獲得することはできません。
- 進捗共通部品が読み込めない場合も、localStorage による保存を使います。
- ブラウザのサイトデータを消去すると、端末内の得点や進捗も消去されます。

## 技術・共通素材

- HTML / CSS / Vanilla JavaScript の静的ページです。APIキー、有料API、データベースは使いません。
- 縮尺ミッションの場面図はページ内のSVGで描画し、画像ライブラリを追加していません。
- ナビキャラは `TT-sensei/navi-character-` のWebP画像を参照しています。画像が読み込めなくても学習できます。
- 進捗は `edu-components` の `StorageManager` / `ProgressManager` と連携しつつ、アプリ側のlocalStorageにも保存します。
- ナビキャラ素材の使用条件は、[素材リポジトリのライセンス](https://github.com/TT-sensei/navi-character-/blob/main/LICENSE)と利用ガイドを確認してください。素材ファイル自体はこのリポジトリへ複製していません。
- 設計方針は [edu-kit](https://github.com/TT-sensei/edu-kit) に合わせ、学習内容・操作を主役にし、キャラクターは補助として使います。
