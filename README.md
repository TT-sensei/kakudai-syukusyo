# 拡大図と縮図ラボ（kakudai-syukusyo）

小学校第6学年 算数「拡大図と縮図」の学習アプリ試作版です。

公開先： https://tt-sensei.github.io/kakudai-syukusyo/

## 収録している学習

- 形のきまり：正三角形・正方形・正五角形・円など、同じ種類どうしで必ず拡大図・縮図の関係になる図形を考える。
- 見分ける：対応する角が等しいこと、対応する辺の長さの比が一定であることを使って判断する。
- 作図ラボ：1つの点を中心にし、中心から各頂点までの距離を同じ倍率にして方眼上に作図する。
- 縮尺を使う：縮尺と図上の長さから実際の長さを求める問題、実際の長さから図上の長さを求める問題に取り組む。

## 小6の学習ポイントの確認

文部科学省の第6学年算数「縮図や拡大図」の資料を参考に、次の内容を入口として扱います。

- 縮図・拡大図の意味と、対応する角の大きさの関係
- 対応する辺の長さの比がどこでも一定になること
- 方眼を使い、1つの点を中心にして作図すること
- 縮図を使って、直接測りにくい長さを求めるための縮尺の考え方

この版は基本の確認用です。今後の拡張候補は、辺の長さと角を使った作図手順、校舎の高さなどを題材にした測量の場面、問題の種類や数の追加です。

- ナビキャラ素材の使用条件は、[素材リポジトリのライセンス](https://github.com/TT-sensei/navi-character-/blob/main/LICENSE)と利用ガイドを確認してください。素材ファイル自体はこのリポジトリへ複製していません。
